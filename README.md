# 지뢰찾기 도우미

찍지 않고 논리만으로 끝까지 풀리는 지뢰찾기를, 막힐 때 한 단계씩 힌트를 받으며 푸는 PWA. 브라우저에서 쓰거나 휴대폰 홈 화면에 앱으로 설치할 수 있고, 설치 후에는 오프라인에서도 동작한다.

**사용하기**: https://itjeong-dev.github.io/MinesweeperHelper/ · 함께 쓰는 앱: [스도쿠 도우미](https://itjeong-dev.github.io/SudokuHelper/) · [노노그램 도우미](https://itjeong-dev.github.io/NonogramHelper/) · [가쿠로 도우미](https://itjeong-dev.github.io/KakuroHelper/)

## 기능

- **새 판**: 크기와 난이도를 골라 시작한다. 시작할 때 가운데 근처의 빈 영역이 열려 있고, 그 뒤로는 찍을 필요 없이 끝까지 풀린다. 고른 크기·난이도는 기억해 두고 `같은 조건으로 한 판 더`로 이어서 푼다.

  | 크기 | 판 | 지뢰 |
  |---|---|---|
  | 초급 | 9×9 | 10 |
  | 중급 | 16×16 | 40 |
  | 고급 | 16×30 (휴대폰에 맞춰 세로) | 99 |

  난이도는 풀 때 꼭 필요한 가장 어려운 기법으로 나눈다.
  - 하: 숫자 하나만 보고 풀린다 (지뢰를 다 찾은 숫자, 닫힌 칸이 모두 지뢰인 숫자)
  - 중: 이웃한 숫자 둘을 함께 봐야 한다 (1-2 무늬 등)
  - 상: 여러 숫자를 엮거나 남은 지뢰 수까지 써야 한다
- **열기·깃발**: 누르면 열고, 길게 누르거나 마우스 오른쪽 버튼을 누르면 깃발을 꽂는다. `깃발` 모드로 바꾸면 반대가 된다. 숫자를 누르면 주변 깃발이 숫자와 같을 때 남은 칸을 한꺼번에 연다.
- **지뢰를 밟으면**: 판 위에 안내가 뜨고 지뢰 위치를 보여준다. `실행 취소`로 밟기 전으로 돌아간다(새로고침 뒤에도 최근 30단계).
- **단계별 힌트**: 힌트를 누를 때마다 한 단계씩 더 알려준다.
  1. 어디를 볼지 (근거 숫자 강조)
  2. 무엇을 찾을지 (기법)
  3. 열 칸·깃발 칸과 이유. `판에 적용`으로 반영한다.
- 진행 상태는 브라우저에 자동 저장된다.
- 새 버전이 배포되면 화면 아래에 새로고침 안내가 뜬다.

### 힌트 순서

잘못 꽂은 깃발 → 숫자 하나(지뢰를 다 찾은 숫자·닫힌 칸이 모두 지뢰인 숫자) → 이웃한 두 숫자 → 여러 숫자 엮기(이어진 숫자를 모두 만족하는 배치를 모두 따짐) → 여러 숫자 + 남은 지뢰 수.

## 키보드

| 키 | 동작 |
|---|---|
| 방향키 | 칸 이동 |
| Space, Enter | 누르기 (열기 모드면 열기) |
| F | 깃발 |
| T | 열기/깃발 모드 전환 |
| H | 힌트 |
| Ctrl+Z | 실행 취소 |

## 개발

```bash
npm install
npm run dev       # 개발 서버
npm test          # 추론·힌트·판 만들기 테스트
npm run build     # dist/에 PWA 빌드
npm run icons     # public/icon-192.png, icon-512.png 다시 만들기
```

main에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 테스트·빌드 후 GitHub Pages에 배포한다.

## 구조

- `src/mines/board.ts`: 판·숫자 계산, 칸 열기(0이면 이어서 열기)
- `src/mines/logic.ts`: 추론 기법 (숫자 하나, 두 숫자, 배치 모두 따지기·남은 지뢰 수)
- `src/mines/hints.ts`: 힌트 엔진 (`findHint`, `applyHint`)
- `src/mines/generate.ts`: 판 만들기 (시작 칸 주변을 비우고 지뢰 배치 → 정한 단계 기법으로 끝까지 풀리는지 확인 → 막히면 막힌 곳의 지뢰를 숫자와 닿지 않은 칸으로 옮겨 다시 확인). 화면이 멈추지 않게 `generate.worker.ts`에서 돌린다
- `src/components/MineBoard.tsx`: 판 (누르기·길게 누르기·오른쪽 버튼)
- `src/components/AppNav.tsx`: 퍼즐 도우미 앱 모음 (네 앱에 같은 파일)
- `src/components/SolvedToast.tsx`: 판 위에 겹치는 안내 (네 앱에 같은 파일)
- `src/components/UpdateBanner.tsx`: 새 버전 새로고침 안내 (네 앱에 같은 파일)
- `src/App.tsx`: 화면
